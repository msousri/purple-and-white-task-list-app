# purple-and-white-task-list-app
A small, interactive to-do list app with a purple-and-white theme. Built with plain HTML, CSS, and JavaScript

**Features**
Add, edit (click any task's text), complete, and delete tasks
Filter by All / Active / Done
A progress ring in the header that fills as you complete tasks
Tasks persist between visits using localStorage
Fully responsive, keyboard-accessible, and respects reduced-motion settings

**Tech**
Just three things: index.html, inline CSS, and vanilla JS. No dependencies, no npm install. This keeps it trivial to host as a static site and easy to explain line-by-line if it comes up in a technical conversation.
